# 本地回归检查

在 Windows 的 Visual Studio Developer PowerShell / Developer Command Prompt 中运行：

```text
python tests/verify_macros.py
```

需要 Python 3、MSVC 和 Windows SDK。检查过程使用临时目录，不修改生产宏，不启动 L-Edit，不改动版图。

- 去掉 L-Edit 特有的 `module { ... }` 包装及文件末尾的顶层注册调用，对七个宏主体按 C11 编译；使用仓库原始 `ldata.h` 核对 UPI 类型与调用签名。
- 指针类型、缺失返回值、对话框数组越界相关编译诊断作为错误处理。
- 从实际宏源码提取被测函数，与 `geometry_tests.c` 的 UPI 替身链接后运行。没有复制一份几何算法代替生产实现。
- 覆盖数值解析、单位换算、变换失败时保留原对象、偏移数组、线段交点、退化线段、较大坐标、极短圆弧、圆拟合、质心、蜂窝阵列唯一性、沿路径布圆、重复删除和分配失败。跟踪被测函数分配/释放平衡。
- 测试独立定义会终止进程的断言：旧版 `ldata.h` 将 `assert(x)` 定义为 `(x)`，不能直接用于回归检查。

原始供应商头文件注释包含非 UTF-8 的版权字符；使用 `/utf-8` 时会产生 C4828 警告，未修改供应商文件。普通的浮点到整数转换警告被禁用；这不表示所有数值边界均由编译器证明安全。

通过这些检查不等于通过 L-Edit 的宏解释器/编译器、真实 UPI 库或版图保存回读测试。集成验收场景见 `docs/代码审查.md`。
